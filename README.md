# Treasury-Bond-Yields-Economic-Policy-Uncertainty-Research
Research project which analyzes the potential for banks or other fixed-income asset holders to use the policy uncertainty metrics like the EPU index for yield forecasting for Treasury bonds.
The Python file and the csv files were used to conduct initial exploratory data analysis on Treasury Bond yield data and the Economic Policy Uncertainty Index.
Since research is not finished, the final paper is not complete, but will include my own data analysis as well as a synthesis of existing similar research for policy uncertainty and fixed income or stock markets.
